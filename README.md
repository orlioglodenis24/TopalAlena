# TopalAlena

Портфолио Topal Alena — 3D Generalist · Motion Designer.

Vite + Three.js + GSAP + Lenis. Все тексты, контакты и проекты — в `src/content.js`.

```bash
npm install
npm run dev     # локально
npm run build   # сборка в dist/
```

Деплой на Vercel: фреймворк Vite, команда сборки `npm run build`, папка `dist`.
